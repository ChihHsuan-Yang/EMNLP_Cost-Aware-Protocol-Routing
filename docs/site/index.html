When is collaboration worth its cost?

We run every problem under four protocols—direct solving, self-correction, planner–executor–reviewer, and multi-agent deliberation—while holding the solver fixed within each setting. In our experiments, confidence helps identify likely failures, but choosing the collaboration protocol that will pay off remains harder. Conservative routers miss useful collaboration; higher-solve frozen routers often spend too many tokens.
